
# 🎩 JURAGAN28 Digital Journal

## 🌐 Tentang JURAGAN28

JURAGAN28 Digital Journal adalah ruang informasi yang membahas budaya permainan digital, teknologi, kreativitas, serta perkembangan hiburan online di Indonesia.

Kami percaya bahwa setiap permainan memiliki cerita, setiap tantangan memiliki makna, dan setiap keputusan membutuhkan pemahaman.

Melalui publikasi ini, kami berbagi pengetahuan mengenai mekanisme permainan, pengalaman pengguna, literasi teknologi, dan pentingnya memahami risiko hiburan digital.

- Desain serta mekanisme permainan
